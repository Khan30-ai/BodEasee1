# BodEase — Diet Consultancy Website

BodEase is a responsive, client-facing web application developed to digitally represent a diet consultancy business.  
The website showcases diet plans, services, and contact information with a clean, minimal, and professional design.

The UI theme and overall design were created based on direct client requirements, with a strong focus on usability and responsiveness across devices.

🔗 **Live Website:** https://bodease.vercel.app
---

## 🚀 Key Features

- Fully responsive design (mobile & laptop friendly)
- Clean and minimal UI designed as per client preference
- Service and diet plan showcase sections
- Optimized layout for performance and SEO
- Deployed on Vercel for fast and reliable hosting
 ---

## 🛠 Tech Stack

- **Frontend:** React.js
- **Styling:** Tailwind CSS
- **Deployment:** Vercel
- **Tools:** Git, GitHub, npm

## 🚀 Getting Started (Run Locally)

Follow the steps below to run this project on your local machine.

### Prerequisites

Make sure you have the following installed:

- Node.js (v16 or above recommended)
- npm or yarn
- Git
  ### Installation Steps

1. **Clone the repository**
   ```bash
   git clone https://github.com/Khan30-ai/BodEase.git

2. **Navigate to the project directory**
   ```bash
   cd BodEase

4. **Install dependencies**
   ```bash
   npm install

6. **Start the development server**
   ```bash
   npm run dev
